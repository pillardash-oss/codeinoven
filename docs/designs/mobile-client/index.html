CodeInOven Mobile client

Send “hi” and the turn starts itself.

One phone, one page. The agent on the other side is scripted: it answers, then asks you a question, requests a permission, wants a secret, and runs a five stage Auto Pilot. Every card is real UI: it folds, counts down while you are idle, pauses the clock while you read, and settles when you answer.

Send hi, then answer the question, the permission and the secret prompt. The run follows on its own.

Try: stop a running turn by emptying the field and pressing stop twice. Queue a message while it works. Fold a card. Expand a file in the diff. Pick a cheaper model and watch the thread header follow. Reload returns the demo to the start.
