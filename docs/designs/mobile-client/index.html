CodeInOven Mobile client, design study
All screens, canvas

Your agents, in your pocket.
Same instrument, one hand.

A standalone client, not a remote control for a desktop window: it starts its own threads, picks its own project, stage and model, and runs engineering work from a phone. Obsidian surfaces, ivory ink, and gold reserved for exactly one thing on each screen, the control that moves the work forward.

What it does

  • Threads, grouped by what they need: attention, working, pinned, recent.
  • Full turns read on the phone, with tool calls and changed files inline.
  • Every approval the desktop asks for: permission, secret, question, gate.
  • Engineering stages from Brainstorm to Achievement, Auto Pilot included.
  • Usage, quota and model choice, in the same units the desktop reports.

What it deliberately leaves out

  • The terminal, the file editor, the embedded browser and the design board.
  • Process management, updater, login items: the phone is not a workstation.
  • Nothing is faked to fill the gap. Omitted surfaces are absent, not greyed.

Rules this study holds itself to

  • Tokens from src/renderer/app.css, dark values only, no invented palette.
  • Oven Box for the interface, Oven Mono for every measured value.
  • 4px spacing unit, 2px corners, hairline rules instead of shadows.
  • Falsy left, truthy right on every card footer and every dialog.
  • 44px minimum touch targets, visible focus, no motion without meaning.
