CodeInOven / assistant orchestrator study
Design study · not implemented

One assistant you talk to. The rest it talks to.

Today the Assistant view opens onto a list, and every conversation starts by choosing which assistant should have it. This study puts a single orchestrator in the centre with a message box that never asks that question. You describe the outcome; it either hands the work to the assistant that already owns it or does it itself, and says which in one line you can fold away.

  • Routing is visible, never modal The decision arrives as a one-line dispatch note under the reply. It expands into the task, the model and how the result comes back, and it collapses to a single line again.
  • The roster stays a roster Assistants keep their rows, states and schedules on the left. The orchestrator is a row at the top of the same list, not a separate mode, so chatting with one directly is one click.
  • One accent, and it means self Gold marks the orchestrator only. Running work keeps the app's blue, done keeps its green. No new palette, no gradient, no glass.

Answered by Chief, alone

Questions about its own assistants (“what did Dependency Watch find?”) are read from their last run and answered in place, because waking an assistant to repeat a summary is work for no reason. Anything that produces or changes something becomes a task with an owner, which is why the third note in screen 01 says “Answered by Chief”.

What is still a guess

Whether a dispatched task should report into Chief automatically, or only when it has something you must decide. Screens 01 and 06 copy the first reading. The second would keep the orchestrator thread nearly silent, and it is the one thing I would settle before building.

What this does not change

Assistants keep their rows, tasks, knowledge, schedules and models exactly as they are, and chatting with one directly is still one click from the roster. The study only adds a row at the top of that list and a console that can address all of them, so nothing already working has to be rebuilt to try it.
