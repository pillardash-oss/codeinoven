CodeInOven · brand work · round eleven

The CIO set, one language pass

Mostly no new iconography here. The set you approved over ten rounds keeps its drawings and its unified 1.9 weight, and what changes is the construction the drawings speak in: square caps and miter joins like the mark, squared solid anchors, one corner rule, and the anchor exposed as a colour variable so state can light it gold the way the mark's knob does. Two glyphs are redrawn on your marks: R-17, the thread note is now the feather you expect, and R-21, the spanner head rotates so the handle plugs flush. Annotate by naming a chip in the thread, for example R-07, or pin notes on the right and copy them back.

CodeInOven the mark this pass answers to

1 · The language

five rules, one yardstick
  • Square caps, miter joins. The mark builds every stroke that way. Round ends were the one unrounded thing the set still drew, and beside the squared C and O they read soft.
  • Anchors squared. Each glyph carries exactly one solid element. Bars become bars, radius 0, like the mark's bar. Dots stay circles, like the mark's knob.
  • One corner rule. Every rectangular container rounds at 2, not the current scatter of 1.6 to 2.6. The beetle keeps its radius 6 as the single organic exception.
  • The weight system carries. Every fitted stroke still resolves to 1.9 effective units, the two redraws included. Nothing is re-weighted in this pass.
  • State lighting. The solid anchor fills itself from var(--icon-anchor), so the current surface can light its anchor in gold. Gold appears only where the mark's own terms put it: on the live thing, never statically.
