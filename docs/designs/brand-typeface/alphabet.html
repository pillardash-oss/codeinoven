Alphabet · Oven Mono v1.000

Every letter, both faces

The alphabet is deliberately unchanged, because JetBrains Mono's letterforms are what make four hours of reading comfortable. Each row sets the cut in play above the same characters in the face that ships today, so any difference you see is a difference I made on purpose. Switch the cut in the bar: Oven Mono changes the marks only, Oven Box changes the marks and squares every drawn corner with them.

01

The character sets

Both faces use weight 300 so weight does not disguise the differences in the letters. Lower case, upper case, figures and the ASCII symbols a shell actually prints.

02

Every mark I changed, one by one

The left glyph is what ships today and the right is the selected Oven cut. Both are set at the same weight. Oven Mono squares the mark's dots and flat cuts its quotes; Oven Box also squares the bowls, shoulders and diagonal vertices. Parentheses stay round so they cannot be read as brackets.

U+002E .. Circle to square, cut to 0.86 so the ink weight holds.
U+003A :: Both dots squared. Still stacks on the same centres.
U+003B ;; Upper dot only. The tail stays a comma, not a dot.
U+0021 !! The point under the stem, squared. Stem untouched.
U+003F ?? The point only. The bowl is a bowl.
U+2026 …… Three squares, squared on their mean width.
U+0027 '' Taper to a flat bar of constant width.
U+201A ‚‚ Same bar, below the baseline.
U+0030 00 The zero's inner dot, squared to match.
U+0069 U+006A ijij Both tittles, squared. The stems are untouched.
U+2022 •• Unchanged on purpose: a list bullet is a bullet.
U+2018 U+2019 ‘’‘’ Unchanged on purpose: prose needs to tell the curl's direction.
03

The code ligatures still fire

A terminal face earns its keep here. Every ligature JetBrains Mono ships is carried through untouched, because a coder reads -> as an arrow, not as a hyphen and a bracket.

-> → ARROW RIGHT
=> ⇒ FAT ARROW
!= ≠ NOT EQUAL
=== ≡ IDENTITY
<= ≤ LESS OR EQUAL
>= ≥ GREATER OR EQUAL
|> ▷ PIPE
<- ← LEFT ARROW
