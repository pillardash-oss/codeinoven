Variant 7

V7 · Fixed spine

One fixed-width column holds identity, back and forward, and the view's actions, each group separated by a hairline. The thread title follows the column, aligned left instead of floating in the middle. The column never changes width when the title does, so the title starts on the same pixel for every thread.

Trade Left alignment is what makes the bar readable at a glance: everything the app is doing reads from one edge, and the right edge is only chrome. It costs a fixed 17rem before the title on every view, which is real space for a long thread name.

Natural gutter

spine starts where the OS zone ends

The column begins immediately after the window controls, so on macOS it starts at 80px and on Windows and Linux at 0 or 138px depending on which edge owns the captions. Inside the column, nothing ever moves.

Hard gutter

one constant inset, all four windows

The same column, preceded by one constant 138px gutter on every platform: the width of a native caption cluster, which is the smallest constant that also clears a Linux desktop that puts close on the left. This is the only arrangement in the study where the identity mark and the title start on the identical pixel in all four windows. On macOS the traffic lights sit inside the gutter, and on Windows it is plain margin, since the captions are on the other edge.
