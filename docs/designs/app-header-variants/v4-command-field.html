V4 · Command field

One field in the middle. Thread state and the right-hand actions become chips inside it, so the bar holds three controls no matter how much the thread needs. The field is centred, so it is the only element that looks identical on every platform.

Trade Feels like an editor rather than a chat app, which suits this product. It hides a working agent behind a chip, so the agent's live state competes with search for the middle of the bar, and the field is the first thing to vanish in a narrow window.
